# 📁 My Drive

## 📌 Description
My Drive is a web-based file management system similar to cloud storage platforms. It allows users to upload, delete, rename, and organize files and folders easily. The project is designed to demonstrate basic file handling and CRUD operations with a simple and user-friendly interface.

---

## 🚀 Features
- Upload files  
- Delete files and folders  
- Rename files and folders  
- Create new folders  
- Simple and clean UI  

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Node JS, Express 
- Database: local & System database 

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/my-drive.git
cd my-drive
npm install
npm start
```

---

## 📖 Usage
- Upload files from your system  
- Create folders to organize data  
- Rename or delete files easily
